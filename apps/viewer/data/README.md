# data — содержимое «Подсмотрщика»

Здесь лежит то, что показывает приложение `apps/viewer/`.

```
data/
├── links.json        ← список: что показывать (правится руками)
└── proto/            ← сами страницы (html), по одной на прототип
    ├── index_1.html
    └── index_2.html
```

## Как добавить прототип

1. Положить файл в `proto/`, например `proto/maket.html`.
2. Дописать строку в `links.json`:

```json
{ "name": "maket", "file": "data/proto/maket.html", "note": "проба" }
```

3. `git push` — через минуту страница видна на сайте в списке «Страницы в data».

Внешняя ссылка (без файла) — та же строка, но с `url` вместо `file`:

```json
{ "name": "макет на фигме", "url": "https://…" }
```

Поле `note` нигде не показывается — это заметка для себя.

## Свои ссылки в браузере

Строка ввода в приложении добавляет ссылку в «Мои ссылки» — они хранятся
только в этом браузере (`localStorage`, ключ `miniapps.viewer.links`) и в репозиторий
не попадают. Чтобы ссылка была у всех, допишите её в `links.json`.

## Правила

* Имена файлов — латиницей, без пробелов.
* Страницы по возможности самодостаточные (без внешних CDN), иначе без интернета
  прототип покажется голым.
* Копия прототипа здесь — снимок. Оригинал живёт в своём репозитории;
  если он изменился, файл в `proto/` нужно заменить.
